Vision Driven Design

MCP 伺服器

為 AI 編碼代理提供規格驅動的方法論——8 個階段、雙向可追溯性及 7 個質量門。

面向 AI 編碼代理的方法論：八個階段、七道質量門——讓「完成」意味著可追溯，而非僅僅能跑。

能力

  • 透過 Streamable HTTP 提供 15 個工具
  • 願景 → 策略 → 戰術 → 規格 → 計劃 → 任務 → 實施 → 驗證
  • 7 個雙向質量門（108 項檢查）；對齊 DO-178C / IEC 62304 / CMMI

連接

將 MCP 客戶端指向託管端點。開放存取，無需 API 密鑰。

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "vdd": { "type": "remote", "url": "https://vdd.simonmak.com/api/mcp" }
  }
}
claude mcp add --transport http vdd https://vdd.simonmak.com/api/mcp
