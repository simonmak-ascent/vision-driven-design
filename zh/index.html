Vision Driven Design

MCP 服务器

为 AI 编码代理提供规格驱动的方法论——8 个阶段、双向可追溯性及 7 个质量门。

面向 AI 编码代理的方法论：八个阶段、七道质量门——让「完成」意味着可追溯，而非仅仅能跑。

个工具
15
个阶段
8
项质量检查
108
开源
MIT

能力

  • 通过 Streamable HTTP 提供 15 个工具
  • 愿景 → 策略 → 战术 → 规格 → 计划 → 任务 → 实施 → 验证
  • 7 个双向质量门（108 项检查）；对齐 DO-178C / IEC 62304 / CMMI

准则

  • DO-178C
  • IEC 62304
  • CMMI

连接

将 MCP 客户端指向托管端点。开放访问，无需 API 密钥。

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "vdd": { "type": "remote", "url": "https://vdd.simonmak.com/api/mcp" }
  }
}
